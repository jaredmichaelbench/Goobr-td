# M2 results: the maze

## Mac Studio (2026-10-24)

- **Rerouting: pass.** "Everything rerouted correctly and felt nice."
- **Difficulty: too easy.** It never started to feel hard. Jared reached wave 9 (then quit by accident with Esc).
- **Economy and relative tower power need a look.** Parked until after M3, because M3 changes how towers fire (on the beat), which changes their damage anyway.

## Changes made from this feedback

- Test tools added (F1 speed 1x/2x/4x/8x, F2 auto-send waves, F3 +100 gold, F4 skip a wave, endless mode after wave 10). The HUD shows next-wave creep count and HP. These are for playtesting only.
- Esc now needs a second press to quit to the menu.

## Verdict

Keep the grid, flow field, and build controls as-is. Move on to M3.
