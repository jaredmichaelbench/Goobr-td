## Card text

| Card | Text |
|---|---|
| Counter Attack | Counterattack may be used after a successful parry on the next beat. Counterattacks cause greatly increased stagger damage (reduced against bosses). |
| Freestyle | Increases the window for a note by +15 ms. |
| Perfect Freestyle | Increases the window for a perfect note by +5 ms. |
| Defensive Percussion | Increases the window for a parry by 25 ms. |
| Poison Tower | Unlock Poison Tower. Show gold cost, stats, description. |
| Slowing Song | Notes slow enemies by 5% (Perfect by 15%), stacking up to 3 times. Capstone. Does not stack with Frost tower. |
| The Right Instrument | Perfect notes have an effect on each tower type. Poison: periodic damage lasts 6 s longer. Frost: freezes the target for 2 s. Cannon: (todo). A cool effect for each. |
| Perfect Solo | Hitting a perfect note on every note of a Crescendo automatically parries and counterattacks for 8 seconds. |
| Improved Restore | Using Restore automatically starts the next Crescendo. |
| Solo | Completing a full Crescendo without dropping a note grants 2 shields and 1 restore. |
| Melodic Healing | Hitting a perfect Crescendo on every note restores 1 health to the Conductor. |
| Grace Notes | Allows 8th notes to accent phrase/note sequences. Successful 8th notes strike for 70% of normal damage; perfect 8th notes strike for 130% extra damage (perfects highly rewarded, regular hits dampened since this is an extra attack). |
