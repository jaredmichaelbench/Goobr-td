# Goobr TD

A maze tower defense where the wave is played, not watched. You build the maze, then you conduct it.

- `docs/`: vision, decisions, tasks, backlog, prototypes, and notes. This is the source of truth. Start with `docs/INDEX.md` and `docs/vision/vision.md`.
- `game/`: the Godot 4.5 project (Demo 0). Open `game/project.godot` in Godot and press F5. See `game/README.md`.
